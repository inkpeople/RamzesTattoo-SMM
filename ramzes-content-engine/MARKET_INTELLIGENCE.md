# RAMZES AI — бесплатный мониторинг рынка

## Как работает
- GitHub Actions запускает анализ раз в 6 часов (4 раза в сутки), а также вручную по кнопке Run workflow.
- Сканируются публично индексируемые объявления, страницы мастеров, публикации Threads и другие открытые материалы по тату-рынку выбранного города.
- OpenRouter анализирует найденные данные и формирует отчёт для личного Telegram-чата.
- История источников, отчётов и идей хранится в SQLite внутри GitHub Actions Cache. Кэш обновляется каждым запуском; GitHub может удалять неиспользуемые кэши, поэтому это не архив с гарантированным бессрочным хранением.
- Отдельный постоянный сервер и платный диск Render не используются.

## Содержание отчёта
1. Рынок и подтверждённые тенденции.
2. Конкурентные предложения, позиционирование, CTA и публично видимые цены.
3. Threads и соцсети: темы, обсуждения и только те показатели вовлечения, которые действительно видны.
4. Аудит RAMZES: преимущества, пробелы в упаковке, доверии, портфолио, контенте, оффере, воронке и локальном поиске.
5. План действий на 7 и 30 дней с показателями.
6. Три новых поста Threads и две рекламные идеи с защитой от повторения недавнего контента.

## Настройка GitHub
В Settings → Secrets and variables → Actions добавь Repository secrets:
- TELEGRAM_BOT_TOKEN — токен @RamzesContentEngineBot.
- TELEGRAM_OWNER_ID — числовой Telegram ID владельца.
- OPENROUTER_API_KEY — ключ OpenRouter.
- BRAVE_SEARCH_API_KEY — желательно, для более широкого поиска.

Repository variables (необязательно):
- OPENROUTER_MODEL — по умолчанию deepseek/deepseek-chat.
- MARKET_MONITOR_LOCATION — по умолчанию Новосибирск, Россия.

Секреты вводятся только в GitHub Settings, не в чат и не в исходный код. Не используй токен другого бота. Если этот Telegram-бот уже обслуживает webhook, worker отправляет сообщения через sendMessage и не меняет webhook.

## Источники и ограничения
- Без BRAVE_SEARCH_API_KEY включается ограниченный Google News RSS fallback; он не гарантирует поиск социальных публикаций.
- Даже с Brave поиск зависит от индексации поисковой системой. Закрытые профили и закрытая статистика недоступны.
- Просмотры/охваты нельзя надёжно определить из поискового сниппета. В отчёте они указываются только при явном наличии публичного числа.
- Лайки, комментарии и репосты — сигналы вовлечения, а не доказательство охвата или эффективности рекламы.
- Это периодический мониторинг, не непрерывный 24/7 процесс. Запланированные GitHub Actions могут запускаться с задержкой.
- GitHub Actions Cache не является долговременной базой: при удалении кэша история начнётся заново.
- Запуск GitHub Actions на публичном репозитории обычно бесплатен в рамках лимитов GitHub; проверь текущие лимиты аккаунта и не добавляй платные сервисы.
