# RAMZES AI — статус реализации

## Этап 1: реестр и маршрутизация — реализован в ветке

Ветка: `ramzes-ai-orchestrator-implementation`
PR: https://github.com/inkpeople/RamzesTattoo-SMM/pull/7

### Что уже работает в коде

- Реестр содержит 37 уникальных специализаций со стабильными ID.
- Детерминированный планировщик выбирает тип задачи и ограниченный состав команды без вызова модели.
- Контентный pipeline возвращает выбранный план и адаптирует результат под площадки, явно названные в запросе.
- Универсальный запуск LLM-специалиста использует ролевые инструкции для новых исследовательских, клиентских и контентных ролей.
- Исследовательский сценарий бота направлен через `run_specialist_team`: исследователь рынка собирает данные, затем подключаются релевантные роли наблюдения за конкурентами/трендами.
- Реализованы Python-инструменты без LLM: оценка заявки по явно указанным параметрам, расчёт экономики скидки, поиск текстовых повторов, аудит источников метрик, проверка черновика публикации и расчёт этапов воронки.
- Результаты и пропуски данных возвращаются в структуре, пригодной для последующего логирования и отчёта.

### Что пока не подключено к живым данным

- Заявки и история записей пока не передаются в lead scoring и funnel tools автоматически.
- Аналитические инструменты ждут реальные метрики в структурированном payload.
- Поисковик клиентов не имеет отдельного универсального коннектора ко всем соцсетям; работает только с доступными публичными источниками через существующий поисковый вызов.
- Долгосрочная память не расширена новыми таблицами/схемами; используется текущий storage adapter.
- Периодические отчёты и GitHub Actions расписание не включены в этом PR.
- Все новые специализации ещё не маршрутизируются из каждого типа Telegram-запроса.
