# RAMZES AI — бесплатный стек и источники данных

## Принцип

«Бесплатно» означает отсутствие обязательных новых платных сервисов, а не гарантию бесконечного бесплатного ИИ или безлимитных API. У каждого внешнего провайдера могут меняться квоты, условия и доступность. Все интеграции должны быть заменяемыми и иметь graceful fallback.

## Уже имеющаяся основа

- Python-код агентов и существующий `model_call`.
- Telegram Bot API для общения с владельцем.
- GitHub для кода, PR, CI и плановых запусков.
- Необязательный Supabase-адаптер в `storage.py`.
- Существующие переменные окружения и Render deployment.

Не создавать новую базу и не менять хостинг до проверки текущих лимитов и согласования.

## Где не нужен ИИ

Делать обычным Python:
- нормализацию и дедупликацию ссылок;
- подсчёт публикаций и метрик;
- поиск повторяющихся тем и текстов;
- расчёт среднего чека, конверсии и динамики;
- расписание и ограничение частоты задач;
- проверку обязательных полей, ссылок и CTA;
- фильтрацию источников и сроков актуальности;
- формирование сводок из уже известных данных.

Это дешевле, быстрее и предсказуемее, чем вызывать языковую модель.

## Где нужен ИИ

- интерпретация неоднозначного запроса;
- стратегический анализ;
- анализ мотивов аудитории с пометкой гипотез;
- создание оригинальных текстов;
- адаптация контента под площадку;
- анализ открытых материалов конкурентов;
- объяснение тенденций в предоставленных метриках;
- подготовка ответов на возражения.

## Провайдер модели

Текущий вызов модели должен оставаться за интерфейсом `model_call`. Не привязывать роли к одному провайдеру.

Рекомендуемая политика:
1. Сначала использовать уже настроенный провайдер и модель, если пользовательские лимиты позволяют.
2. Бесплатный провайдер подключать как необязательный адаптер только после проверки актуальной квоты и условий.
3. При исчерпании квоты не переключаться на платный тариф автоматически.
4. Детерминированные задачи выполнять локальным кодом.
5. Локальные модели (например, через Ollama) считать вариантом для отдельного компьютера/сервера пользователя, а не гарантированно бесплатной функцией текущего Render deployment.

## Открытые источники

### Приоритет 1 — RSS и публичные страницы
- RSS-ленты профильных изданий, блогов и открытых площадок.
- Публичные страницы студий и мастеров, доступные без обхода авторизации.
- Публичные страницы мероприятий, фестивалей и локальных сообществ.
- Публичные поисковые результаты, если их использование разрешено условиями источника.

### Приоритет 2 — официальные API с бесплатными квотами
Подключать только после проверки текущей документации, лимитов и условий:
- API поисковых сервисов;
- API площадок для авторизованных аккаунтов;
- API аналитики, если пользователь предоставил доступ;
- публичные каталоги и открытые наборы данных.

### Приоритет 3 — данные владельца
- статистика публикаций, которую пользователь прислал боту;
- выгрузки CSV/XLSX;
- данные VK/Instagram/Telegram из официальных кабинетов;
- сообщения о заявках и записях, переданные владельцем;
- портфолио, загруженное владельцем.

### Что не обещаем
- доступ к закрытой статистике чужих аккаунтов;
- точные рекламные бюджеты конкурентов без публичного источника;
- гарантированный сбор всех постов из Threads/Instagram/VK;
- бесплатный безлимитный поиск;
- точную частотность Wordstat без подходящего доступа;
- доступность бесплатного тарифа конкретного провайдера навсегда.

## Контракт источника

Каждый адаптер возвращает нормализованную запись:
- `source_id`;
- `source_name`;
- `url`;
- `title`;
- `published_at` (если источник сообщает);
- `fetched_at`;
- `excerpt`;
- `content_type`;
- `confidence`;
- `limitations`.

Любой отчёт должен отделять:
- подтверждённый факт;
- интерпретацию;
- гипотезу;
- неизвестные данные.

## Бюджет и защита

- Ограничивать число источников на один запуск.
- Кэшировать результаты и не скачивать повторно неизменившийся контент.
- Не выполнять бесконечные циклы повторных запросов.
- Вводить таймауты, retry с backoff и общий лимит времени.
- Не логировать токены, ключи, личные сообщения и полные клиентские данные.
- Не собирать специальные категории персональных данных и не строить чувствительные профили людей.
- Не обходить CAPTCHA, paywall, авторизацию или технические ограничения площадок.

## Безопасность действий

RAMZES AI может подготовить публикацию, ответ или кампанию как черновик. Публикация, реклама, массовые сообщения, запись/отмена сеанса и контакт с потенциальным клиентом требуют явного подтверждения владельца.
